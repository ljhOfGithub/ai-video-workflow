# 原创 SVG 道具

每个 SVG 可单独放入编辑器或作为 HTML 图层。文件自带透明背景和 `viewBox`，可以修改 `fill`、`stroke` 或圆角。文字用视频工程的独立图层添加，便于改语言、字体和排版。

- [按钮底板](button.svg) 可以配「保存」或其他操作标签。
- [鼠标指针](cursor.svg) 可以移动到按钮或高亮目标。
- [进度条](progress.svg) 可以动画调整填充矩形宽度，原始状态约为 70%。
- [成功状态](success.svg) 可以和「已保存」等确认文案配合。
