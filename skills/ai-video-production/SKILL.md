# AI 视频制作与验收

1. 确定观众要学会什么、成片类型、比例、时长、素材来源及交付形式。读取实际媒体规格。已有工程时先找最近一次通过审核的素材与决定。
2. 写[分镜与素材表](references/storyboard.md)。短教程为每个知识点安排一个实际操作、可见反馈和旁白解释。参考片改编先按镜头与台词核对时间，用[改写与配音表](references/adaptation.md)保留逐句对应和声音节奏。
3. 出关键画面，标明画幅和移动边界。适合画面定稿的任务用关键图确认，涉及卡点或移动时用动态预览。遵循该项目明确要求的审核顺序。
4. 按已定画面、口播与时间线编排，用指定引擎实际导出。第三方模板保留原包、版本、许可和引擎回执。按镜头检查字幕、动作与状态响应。
5. 在最终媒体文件上运行[验收](references/qa.md)。字幕或文字密集的成片每 0.5 秒抽一帧做 OCR，切换、遮挡、闪帧和动作极限按需加密或逐帧看。OCR 输出供比对，识别错误和漏字需回看真实帧。完整解码、音频、字幕同步和播放器检查要分别留证。
6. 交付可打开的成片和可重建的工程。列出通过范围、警告、未验证项、工具版本和实际规格。修改后检查受影响的镜头并验证新的交付文件。
