## 媒体技术检查

需要安装 FFmpeg。在视频文件所在目录运行，并把示例文件名换成实际路径。

```bash
ffprobe -v error -show_format -show_streams -of json ./成片.mp4
ffmpeg -v error -xerror -i ./成片.mp4 -map 0:v:0 -map '0:a?' -f null -
ffmpeg -hide_banner -i ./成片.mp4 -vn -af ebur128=peak=true -f null -
shasum -a 256 ./成片.mp4
```

## 半秒 OCR

在 macOS 13 或更高版本安装 Swift 工具链。从本 Skill 目录运行。命令参数依次为视频路径和输出 JSON 路径，报告目录需已存在。

```bash
swiftc -parse-as-library scripts/ocr_video.swift -o ./ocr-video
./ocr-video ./成片.mp4 ./ocr-report.json
```

脚本从 0 秒起每 0.5 秒请求一帧，采样点小于视频轨道结束时间。默认使用简体中文和英文 OCR，也可传第三个参数如 `en-US`。报告列出请求时间、实际取帧时间、识别文本、置信度和归一化文字框。文字框左上角为原点，坐标和尺寸取值约在 0 到 1 之间。没有识别文字的帧保留空数组。若任意帧无法读取或 OCR 失败，脚本返回非零退出码，且不覆盖既有报告。每次验收建议使用新输出路径。

其他平台可使用 FFmpeg 抽取同样的时间点，再用当地安装的 OCR 工具处理。遇到光标、细像素字体或短暂字幕时回看原始帧。半秒采样适合初筛，转场和短闪另按实际帧验证。
