# 虚构示例：15 秒教会观众保存草稿

目标是让第一次使用编辑器的观众学会确认草稿已保存。画面用虚构的编辑器。声音可用自己的录音。示例文字和时间仅用于演示流程。

| 时间 | 操作与响应 | 旁白与字幕 |
| --- | --- | --- |
| 0–3 秒 | 先展示文档角落的成功图标和「已保存」 | 「改完草稿，先确认它保存了。」 |
| 3–7 秒 | 光标移向保存按钮并点击一次 | 「写完后，点右上角的保存。」 |
| 7–11 秒 | 按钮进入处理中，进度条走完 | 「等保存完成，先别关页面。」 |
| 11–15 秒 | 显示成功图标和「已保存」，光标移开 | 「看到已保存，就可以关掉了。」 |

可直接拿[四个 SVG](../props/README.md)搭画面，用文本层补上「保存」和「已保存」。关键画面审查开场结果、光标点击和最终状态。技术检查可以采样 0、0.5、1.0 秒，依次直到视频结束前的最后一个半秒点。重点人工复核点击后状态是否变化、进度是否在反馈前结束，以及「已保存」在旁白说到时是否可见。
